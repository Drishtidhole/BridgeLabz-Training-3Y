1. Difference between Frontend, Backend, and Full-Stack Development
Frontend Development: Develops the part of a website that users see and interact with using HTML, CSS, and JavaScript.
Backend Development: Handles server-side logic, databases, and APIs using languages like Java, Python, or PHP.
Full-Stack Development: Works on both frontend and backend to build complete web applications.

Example: In Amazon, the product page is frontend, order processing is backend, and a full-stack developer can work on both.

3. How a Browser Requests and Displays a Web Page
1.User enters a website URL.
2. Browser sends an HTTP request to the web server.
3. Server processes the request and fetches data if needed.
4. Server sends HTML, CSS, and JavaScript files.
5. Browser renders the page and displays it.

5. What is a Web Server?
A web server is software that receives requests from browsers and sends web pages to users over HTTP/HTTPS.

Examples:
Apache
Nginx
Microsoft IIS
Apache Tomcat

6. Roles in a Web Development Project
Frontend Developer: Designs the user interface and user experience.
Backend Developer: Develops server-side logic, APIs, and manages databases.
Database Administrator (DBA): Maintains, secures, and optimizes the database.
