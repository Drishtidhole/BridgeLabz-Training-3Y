Responsive Design

Responsive design makes a webpage adapt to different screen sizes using flexible layouts, media queries, relative units, Flexbox and Grid.

CSS Cheat Sheet

  • Flexbox: display: flex;
  • Grid: display: grid;
  • Media query: @media
  • Flexible image: max-width: 100%;
